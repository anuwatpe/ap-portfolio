# Changelog

All notable changes to ONTHAI Lab are documented in this file.

## [0.1.0] - 2026-09-14

Public Preview release of the ONTHAI Lab academic portfolio website.

### Added

- Separate Lab and PI Profile content paths.
- Research scope, active projects, news, teaching, lectures, and Lab Members sections.
- PI Profile sections for selected research, professional experience, education, academic service, awards, honors, and grants.
- English and Thai language switching.
- Responsive shared navigation with a mobile menu.
- PI Profile local navigation for Overview, Experience, and Education.

### Changed

- Standardized the primary navigation across the Lab and PI Profile surfaces.
- Kept PI-specific sections out of the global navigation to make the Lab and PI roles easier to distinguish.
- Standardized the PI Profile label across site pages.

### Notes

- This release is a Public Preview.
- Some people, project, news, and publication records remain mockup content and should be replaced with verified data before `v1.0.0`.
- The site remains a static HTML and Tailwind CSS project intended for GitHub Pages.
